# gbdTools
Some convenient tools for gdb(C++), wrote using Python

It works only with C++ now  
My compiler: g++ (Ubuntu 13.3.0-6ubuntu2~24.04) 13.3.0  
My GDB: GNU gdb (Ubuntu 15.0.50.20240403-0ubuntu1) 15.0.50.20240403-git

Supporting for another compilers may appear in feature.  

**TESTED ONLY ON LINUX**

# Installing
Make `git clone https://github.com/oppovl/gdbTools.git` to any directory you want.  
Next open GDB and use `source *your_directory*/gdbTools/gdbTools.py`.  
You should see the welcome message

Or you can add `source *your_directory*/gdbTools/gdbTools.py` to your *.gdbinit* file
